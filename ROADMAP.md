# Roadmap

## Available in 2.4

Local workspace/navigation, bookmarks, developer tools, notes/projects, configured AI chat, file/media utilities, read-only server diagnostics and local Pixel Office task/review flows. See the README and tool guide for exact boundaries.

## Planned; not delivered as verified capabilities

1. Android emulator/physical-device acceptance and mobile-specific polish.
2. macOS/Xcode iOS build/signing/device validation.
3. Accessibility and physical-input/DPI checks on Windows.
4. Feedback-driven reliability improvements for large files and tool workflows.
5. A considered cloud/sync design only after infrastructure and security requirements are available.

No release date or universal platform parity is promised. Planned tasks are not advertised as current functionality.
