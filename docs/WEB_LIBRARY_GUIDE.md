# 网站导航 · KADO Desk 2.3

在工具中心打开“网站导航”。首次进入建立16个默认分类与20条精选推荐；完整目录有111个官方候选。推荐与个人收藏分开，未收藏或固定的推荐不会进入首页常用收藏，删除过的推荐不会在升级时自动复活。目录可按名称和分类筛选，明确选中后添加。

添加网站：填写名称和网址，缺协议时补https://，选择分类、标签、描述和可选备用网址。只接受HTTP/HTTPS；查询参数和fragment保留。保存后可在网站菜单编辑、收藏、固定首页、设置自定义图标或移入回收站。首页“移除收藏”会取消网站收藏/固定，保留导航记录；网站回收站可恢复记录，原分类不存在时移至未分类。

搜索支持名称、域名、描述、标签及分类；Ctrl+F聚焦。桌面显示分类侧栏，窄屏通过分类按钮选择。可切换网格/列表和紧凑/舒适密度，设置保存在本机。每页60项，上一页/下一页分页。最近访问仅在系统打开成功后写入；在工作台设置关闭访问历史后不再增加网站访问统计。

分类管理：新建/编辑名称、描述、图标、颜色和上级，最多两层；不可形成循环。拖动调整同一层级顺序。隐藏会隐藏分类及其网站，可在管理页恢复显示。删除分类必须选择网站去向，子分类保留到顶层，不会顺带删除网站。网站拖动排序在导航管理菜单，固定项仍显示在前。

批量操作：勾选网站后，可移动分类、追加标签、收藏或移入回收站。批次会检查选择时的版本；若另一操作已修改记录，会提示重新选择，不覆盖新数据。

导入/导出：导航管理菜单→导入/导出。主动选择UTF-8 Netscape HTML、JSON或CSV，最多20MiB、10000个网站。先解析错误与重复，再生成写入预览，最后确认。可选择合并分类/保留已有记录/归入新建导入分类；重复规范化URL跳过，不凭同名覆盖。深层浏览器目录合并为两层，保留来源路径。未完成预览保存在本地，可重新打开或删除；数据发生变化后必须重新预览。任务中断不会自动重放。

JSON是完整往返格式，保留分类关系、稳定UUID、顺序、收藏/固定、访问次数/日期及自定义图标。完整JSON可明确选择替换未修改默认推荐；已修改、收藏、固定或访问过的记录保留。HTML用于浏览器目录，CSV用于表格；CSV会转义公式前缀，不能代替保留全部元数据的JSON。导出先准备受管文件，再调用系统保存；取消保存不会报告“已保存”，可从任务输出重新保存文件。

自定义图标是用户附件，进入全量备份。网站favicon是独立的32MiB缓存：仅在主动读取时请求目标站点自己的/favicon.ico，不使用第三方favicon服务，不跨站追随图标跳转，不在渲染卡片时联网。缓存缺失时依次回退分类图标；清理缓存不删除自定义图标。

公开标题/描述读取同样需要点击。每次跳转检查公共地址、限制端口、超时、大小和重定向次数，并固定解析后的公共IP。Windows检测到系统代理/PAC/自动检测或无法确认策略时拒绝此可选读取；其他平台目前保留手动填写与系统浏览器入口。不会修改或绕过网络设置，不会因读取失败拒绝手动保存网址。

Studio的bookmarks.search使用只读个人网站搜索，不初始化推荐、不抓取收藏页面、不把候选目录视作个人常用。浏览网站与向外发送资料是不同操作。

本轮Android仅构建和签名核验，尚无真机/模拟器；iOS资源已准备，尚无macOS/Xcode编译与设备验证。Windows手机宽度截图是响应式布局证据，不代表Android设备验收。


2026-10-26存储兼容核查：Windows的path_provider_windows2.3.0与flutter_secure_storage_windows4.2.2都根据EXE的CompanyName/ProductName构造目录。ProductName保留Links Toolbox、CompanyName保留Links Tam，作为固定的数据/凭据身份；FileDescription、窗口、Flutter界面、安装/卸载入口和图标显示KADO Desk。config/brand.json的compatibility字段与sync_brand.py阻止品牌同步误改存储身份；打包前必须比较新旧实际EXE元数据及依赖锁，并核对二进制SHA。测试不扫描、移动或读取现有用户数据库及凭据。便携模式和显式data-dir保持原行为。
