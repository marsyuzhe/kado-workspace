# 使用说明

## 开始使用

Windows便携版完整解压，双击links_toolbox.exe。不要只复制EXE或删除随包DLL/data。带portable.flag时数据在程序旁user-data；去掉该标记后使用系统应用数据目录，这不会自动搬移旧数据，切换时请使用完整备份恢复。也可用 `links_toolbox.exe --data-dir=<绝对路径>` 指定独立目录。

安装版解压或运行安装器，安装到当前用户LocalAppData/Programs/Links Toolbox，创建开始菜单入口。程序未做商业代码签名。交付目录包含来自Visual Studio可再发行目录的应用本地VC143 x64 CRT DLL；系统组件由Windows提供。若仍提示运行库缺失，可使用Microsoft官方运行库修复。本机原生验收环境已有运行库，未宣称在全新Windows机器完成验收。

Android在系统允许安装本地APK后打开Release APK。该包使用独立本地开发签名；旧Debug APK签名不同，无法直接覆盖安装，请先保留旧数据再处理安装。当前无Android设备，安装/文件选择/后台切换需实机复核。对外访问权限为INTERNET；AndroidX还生成应用自身的内部接收器保护权限，无额外运行时授权弹窗。不申请全盘扫描或后台剪贴板权限。

## Hub

星标模块或添加网址、程序、文件/目录收藏；编辑分组、置顶并调整顺序。应用程序参数单独传递，不执行shell拼接命令。打开文件/程序前检查目标并确认。最近使用记录可在设置中关闭或清空。

顶部搜索与Ctrl+K可检索模块和本机记录。中文短词使用参数化子串查询，长词使用FTS5 trigram；方向键选择，Enter打开，Esc返回。Windows快捷键默认Ctrl+Shift+Space，设置可修改或关闭；冲突会提示且不保存成已注册状态。

## Clipboard

Windows默认不监听，点击“启用”并阅读提示后才记录后续复制事件。暂停/私密模式停止自动收集；私密模式下主动保存会标记敏感。程序不能可靠识别所有秘密，复制敏感内容前请暂停。文本64KB、PNG2MB/4096边长/838万像素，最多500条；收藏不按期限清理。

可主动粘贴、手动保存、搜索、收藏、重新复制、编辑提示词、删除、清空。右键或菜单可把选定文本保存为Memory笔记或插入AI草稿。移动端只实现主动文本操作；不伪装后台全局监听或图片粘贴。

## Archive

Windows通过系统选择器添加目录，点击已授权目录扫描。显示数量、大小、分类、最大/最近文件和错误；可取消。符号链接不递归，单次上限50000个文件。分类扩展名规则可编辑。

重复检测依次使用大小、首尾快速指纹和完整SHA-256。选择文件后生成重命名、复制或移动计划，检查每个“原名→新名”和错误后确认执行。目标存在时不覆盖；同盘移动使用Windows原生MoveFileW，跨盘移动请改用复制。日志记录逐项结果。

条件撤销会重新校验内容，原路径被占用或目标内容已变化时拒绝覆盖。复制撤销将副本移入目标旁.links-toolbox-recovery目录，保留内容。操作中断后pending项需要核对实际路径，不自动猜测成功。不要在外部程序同时编辑被操作文件。

手机通过文档选择器导入应用内副本（单文件100MB），后续操作作用于副本，原始系统文档保持原样。搜索某个已扫描文件后，可把元数据保存为笔记或明确复制此文件为附件（25MB）。

## Memory

创建项目，填写介绍、技术栈和进度；创建笔记并设置项目、标签、收藏、敏感标记与上下文类型。Markdown正文在SQLite，600ms后串行自动保存；切换页面前会等待保存，冲突或失败时保留草稿，可另存为笔记。单篇上限1MB。

支持标题和正文中文检索、Markdown预览、Markdown导入/导出、附件、笔记关联、提示词模板。外部图片默认不加载，避免笔记打开时自动发出网络请求；HTTP/HTTPS链接点击后才由系统打开。

选中项目后导出上下文：先勾选非敏感笔记，再预览CONTEXT.md/PROJECT.md/DECISIONS.md/LESSONS.md/WORKFLOWS.md，最后选择目录。已有同名文件不会覆盖。笔记可送入AI草稿，仍须用户编辑并点击发送。

## AI Desk

添加服务，填写合法Base URL（通常含/v1）、API Key、真实模型ID。OpenAI官方地址为https://api.openai.com/v1；兼容服务必须HTTPS，仅本机loopback允许HTTP。修改服务来源需要重新输入Key，重定向不会携带Key自动跳转。

测试连接会读取/models；不支持时可手动设置ID。新建对话后编辑并发送，可停止、复制回答/代码、切换模型、重试失败轮次和管理历史。取消后不会接收迟到内容。ChatGPT订阅不是API配额。

优先展示服务端Usage；未返回时标明按字符粗算的估算，不能代替服务商账单。费用使用用户填写的输入/输出每百万Token单价和币种；未填写时显示不可用。模型拒绝参数时清空temperature或关闭Usage兼容选项后重试。

## Server

添加自有Linux服务器，选择密码或key认证；私钥使用系统文件选择器导入，可填写私钥口令。首次连接必须通过服务器控制台等可信渠道核对SHA256指纹；以后固定该指纹，变化时拒绝连接。

连接后手动刷新CPU（两次/proc/stat差值）、内存、根分区、运行时间、发行版及Docker容器。未安装/无权限/不兼容的指标显示不可用。只发送内置只读命令，没有启停容器或任意shell入口。可保存脱离凭据的配置说明或敏感监控笔记。

网站监控独立于SSH：点击检查发送HTTP请求，记录状态、耗时、检查时间和成功HTTPS连接的证书到期日；不自动跟随重定向，不把Ping当成网站健康证明。
