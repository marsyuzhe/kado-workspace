# KADO Desk v2.4.0

A modular, local-first workspace for daily developer tools, useful links, notes and configured AI workflows. Created and maintained by Links Tam.

## Added and improved

- Fixed Web Library entry, two-level collapsible workspace navigation, saved width/state, compact homepage and consistent density.
- API Studio, JSON/YAML formatting/diff, Regex Lab, SHA256/512 file checks, snippets, explicit network diagnostics and paginated logs.
- Public GitHub project/release records, static dependency inspection, environment differences and supported file-operation workflows. Docker read-only views reuse SSH/fingerprints.
- Original six modules and Pixel Office remain available; low-frequency legacy modules can be shown in Settings without deleting records.
- Public MIT source, bilingual documentation, real synthetic-data screenshots, full third-party texts and build metadata without personal absolute registrant paths.

## Validation and limits

Public-copy analyze is clean; 240 unit/Widget tests passed with 9 conditional skips. Seven native captures and the final native core/HTTP/drop check passed. Windows Release portable/install/uninstall and isolated 2.3/2.0 upgrade checks passed. Android source Release builds and final maintainer signatures were verified.

Windows is locally unsigned. Android emulator/device and iOS/Xcode are UNVERIFIED; no IPA. Physical hotkey/Explorer drag/DPI, user remote Docker, true cold-cache and 30-minute memory need separate validation. External AI/SSH and FFmpeg/Whisper/models require user configuration; optional engines/models are not included. Cloud sync is unconfigured.

## Downloads and first use

Choose Windows Setup for installation, or extract the entire Portable ZIP and keep DLLs/data. For Android use arm64 or the three-ABI Universal APK; both are Release builds signed with the existing maintainer development certificate. A differently signed installed app cannot be overwritten safely; back up before uninstalling. GitHub Source code ZIP is not an installer.

Verify SHA256SUMS.txt. LICENSE.txt applies MIT to project code, while THIRD_PARTY_NOTICES.zip preserves separate dependency/asset terms. Configure external providers only when needed and review file changes before applying them. No automatic GitHub publication was performed by the preparation tools.
