# 使用 Pixel Studio

1.6：工具栏“环境”可跟随本地时间或固定白天/傍晚/夜间，保存环境和相机。右键/长按人物打开菜单、双击人物聚焦。椅子不可用作捷径。角色配置可编辑显示名、岗位、描述与启用状态，历史保留固定角色ID。

任务中心新增看板、搜索、排序；排队菜单设置P0–P3（P3最高），服务按持久化优先级串行派发，不抢占当前任务。历史导出最近100项及有上限的日志和产物引用；详情可单独导出Markdown。

Byte“Codex本地诊断”仅检查用户确认的exe版本与协议能力，不创建编程任务，不代表账号连接。当前CLI缺少本适配所需读取范围字段，执行未启用，详见CODEX_INTEGRATION.md。

先用设置中的完整 ZIP 备份保留原 V1.0 数据。Studio 继续使用 Schema3，不需要覆盖或替换用户数据库；首次进入仅增加独立的工作室记录。

1. 进入“AI 工作空间 → Links Studio”。六名原创像素角色与办公室在本机运行，不需要服务器或 API。
2. 点击空地让 Links 沿可通行路径移动；点击 Byte/Nova 等角色打开资料。拖动平移、滚轮/双指缩放、工具栏回全景或聚焦。
3. 在 Memory 新建普通笔记，再给 Nova 安排“搜索知识库笔记”，填写实际关键词。员工会去工位，执行现有检索服务；任务中心提供结果、校验值和逐项真实事件。
4. 点开任务，审核通过，再“存入 Memory”。成果保存为敏感笔记，不覆盖源文；重复点击不会产生重复笔记。执行器不提供暂停时可取消；失败可查看原因后安全重试一次。
5. Archive 相关任务只接受已授权目录；网站任务只接受已配置网站并要求确认联网目标。项目上下文任务必须明确勾选笔记，产物先以 Markdown 预览，不直接写入外部目录。
6. 模型管理复用 AI Desk：先配置 Provider/Key，再在员工面板选择 LLM API 执行器和 Provider。每个 AI 任务显示资料范围与外发目标，需要确认。无配置不能假装完成；角色身份不绑定特定供应商。当前为 OpenAI/兼容协议，没有 CLI 或原生 Anthropic/Google 集成。
7. 点击工位可编辑网格坐标和角色；保存时校验重叠、入口和通路。会议桌保存你填写的议题/纪要，不伪造 AI 会议。

离开办公室标签页或应用进入后台时停止非必要渲染；任务服务独立运行。系统终止应用后的未完成任务会标为中断，需要手动核对重试。移动布局截图来自 Windows 引擎视口检查；Android/iOS 设备尚未验收。

V2.0 的十四项扩展工具、多模型有界协作、完整家具编辑器与云同步仍按路线图继续，当前里程碑不代表它们已实现。
