# Pixel Studio 交互与数据

使用 Flame 1.38.2（稳定版）GameWidget；官方资料：https://docs.flame-engine.org/latest/flame/camera.html、https://github.com/flame-engine/flame 。不用 WebView，不替换 Flutter 主框架。

逻辑场景20×14、32px格，人物32×48。整数像素位置、最近邻纹理、1–4倍相机缩放（手势结束吸附）、拖动/聚焦/全景。六人分层原创素材与17×8帧定义在source_assets和生成脚本，进入办公室才加载。缩小视口仍采用最近邻，不宣称全部物理像素均整数倍。

OfficeLayout payloadVersion=1/tileMapVersion=1；家具网格坐标、工位角色/项目关联。保存前验证边界、重叠、入口、入口至全部工位 A* 路径。用户坐标单独保存。碰撞区域以网格定义；当前不模拟角色彼此推挤。

1.6椅子仅作为所属角色工位目标，不可借道、占用他人椅子或堵入口。统一动画控制先坐下再工作，离座先起身再移动。旧已完成任务不重复庆祝，取消其他排队任务不覆盖当前工作状态。会议/交付帧已提供，完整交接编排和闲逛仍待办。

OfficePresentation独立version1保存环境与相机，旧布局无需DDL迁移。默认本地时间6–17白天、17–21傍晚、其余夜间，可手动固定。像素窗景、灯光与真实墙钟，屏幕仅在真实工作时滚动；环境不修改任务。加入选择脚环/悬停、精确人物双击、右键/长按菜单。

MovementController 在逻辑层按路径移动，只有移动期间存在计时器；Flame 读取位置/状态，无 SQLite/网络请求。页面关闭释放图像；任务服务继续执行。应用挂起渲染暂停；移动系统可能终止进程，重启后未完任务标为中断失败，需要用户重试。

角色点击打开 Inspector；空地移动 Links；工位支持坐标/角色调整。会议保存用户亲自填写的纪要，再移动参与者；明确标记本地模式，没有随机生成的 AI 对话。当前家具编辑仅工位；其他家具布置、完整开发管理台、独立 Demo 沙箱和高级闲逛留在后续阶段，未做可用声明。
