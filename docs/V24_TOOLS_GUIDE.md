# V2.4 开发工作台使用与边界

首页/网站为始终可用的Core入口；其他可选模块可以禁用，Disabled状态保留数据和原有路由守卫。网站导航在侧栏首页下方，科技工作空间有两层折叠。顶部Ctrl+K可搜索模块与本地记录；打开隐藏分类中的模块会展开对应分类。拖动侧栏右边缘调宽，底部可进入紧凑模式。设置里切换密度，模块管理中找旧版扩展。隐藏/禁用不删除资料。

|工具|操作与限制|
|---|---|
|API Studio|六种方法、Query、Headers、JSON/Text/Form URL Encoded、1–120秒超时、取消、响应状态/耗时/头/大小/JSON树；保存请求、集合/项目、收藏和基本配置导入导出。显式请求可访问本机/LAN，禁止自动跳转。响应最多8MiB，Body最多2MiB。没有multipart文件上传。|
|安全变量|环境里填写Base URL/普通变量/敏感变量；请求用`{{baseUrl}}`、`{{变量名}}`。敏感值使用系统安全存储，普通数据库和导出只有引用；已识别的Authorization/Cookie/Token/密码字段保存时自动保护。任意Text Body或自定义名称无法可靠自动识别，请使用敏感变量，分享前检查。未填写Key不会伪造成功。|
|Data Formatter|JSON格式化、压缩、验证、树、复制/导入/导出、JSON Pointer差异；YAML由官方Dart库解析。YAML格式化/JSON→YAML输出YAML1.2可解析的JSON流式语法，不保留注释、锚点或排版。复杂键、循环别名、非JSON类型会报错。2MiB、64层、100000节点、5秒后台预算。|
|Regex Lab|Dart RegExp、大小写/Multiline/DotAll/Unicode、范围与分组/命名组、匹配高亮、替换预览、常用规则和表达式历史。UTF-16索引；替换`$1`/`${name}`/`$$`。独立isolate，1秒预算可终止；模式2000字符、文本200000字符、最多1000项。|
|Hash Inspector|选择或Windows拖入最多100个文件，分块SHA256/512、进度/取消、预期哈希对照、清单导出。输入改变会失败。Windows拖入只在本页接收；移动端用选择器。批量计算与单预期值对照，不解析外部SUMS文件。|
|Snippet Library|名称/代码/语言/分类/标签/收藏、搜索、基本高亮、复制与JSON导入导出。Clipboard/Memory/AI Desk可手动保存到同一存储。敏感Memory笔记不开放该转存入口。导入导出最多1000条/2MiB（超过可筛选导出）；每片段200000字符，不执行代码；搜索每页200项，展示预览12000字符。|
|Network Inspector|明确输入单个主机/端口：DNS、TCP、HTTP状态、TLS证书主体/颁发者/有效期/指纹/信任状态、耗时；主动查看本机接口与Windows连接/监听进程。无网段扫描。TLS诊断允许读取不受信任证书并明确标记，不发送HTTP或凭据；普通API/元数据TLS规则不放宽。|
|Log Viewer|用户选择TXT/LOG/JSONL，仅按UTF-8流式读取（非法字节替换显示；导出是UTF-8文本筛选结果，不是二进制副本）、关键词/级别/ISO8601时间筛选、200行分页、字节游标、复制/导出。单行最多16KiB并标记截断；导出也保留截断标记，最多100MiB。可中止后台扫描；文件变化要求重载。选行→脱敏预览→AI草稿，不自动发送；自动脱敏可能遗漏。|
|GitHub Projects|手动读取公开仓库信息与最近10条Release，收藏/最近打开/Issue与Release入口、本地目录关联。不要求Token、不克隆、不执行代码。限流/访问错误原样显示，不伪造缓存。|
|Dependency Inspector|主动选择pubspec.yaml/package.json/requirements.txt/Cargo.toml，离线列出声明约束与作用域，检查结构。JSON/YAML/TOML使用库；requirements选项和引用文件不执行、不跟随。最多2MiB/5000项。不检查最新版本或漏洞，不把声明约束当已安装版本。|
|Environment Diff|选择两份environment.json，可再选对应software-list.csv；显示工具/软件新增、移除、版本变化，以及环境变量名称增减。只输出白名单名称和版本，不读取/导出值或配置正文。|
|Local Workflow|选择输入/输出目录，表单步骤copy/json-format/json-minify/yaml-json→SHA256/512→新文件导出；可存模板，每次重新授权输入/输出，最多8步。复用任务队列、取消与安全独占写入。格式步骤2MiB，复制/哈希1GiB；无脚本执行器。|
|Docker|在原服务器模块连接并核对SSH指纹后查看。镜像、状态、资源和200行日志只读；命令仅固定形式与严格十六进制容器ID。没有重启/删除/修改入口，也没有第二套认证。需要用户已有可访问服务器；没有替用户购买或部署。|

通用限制：JSON树每分支最多200项/16层，纯文本输出预览有长度限制，完整有界结果可复制或导出。错误响应不是成功任务，取消不发布未完成文件哈希。文件处理保留输入，不自动覆盖同名输出。大型Whisper/FFmpeg模型继续外置，未下载或删除任何用户模型。

开发测试：先用`scripts/dev.ps1 test`准备纯合成16MiB哈希样本、241.9MB日志和本机TLS测试证书，然后串行Flutter测试；测试证书只在QA目录，不安装到系统信任库。公开GitHub和可选引擎验收单独显式运行。源包不包含任何QA大文件、测试私钥、实际用户数据库或签名Key。
